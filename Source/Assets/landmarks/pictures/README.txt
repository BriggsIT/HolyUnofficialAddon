Landmark pictures
=================
Put a few gameplay screenshots of each landmark in its folder below (PNG or JPG, any size: the addon crops them to
4:3 and scales them to 640x480). Each landmark game shows one of them, the same one every time. A landmark without
pictures shows the game's usual screenshot. The build installs them; Publish-Repo.ps1 leaves them out of the repo
unless it's run with -Pictures.
